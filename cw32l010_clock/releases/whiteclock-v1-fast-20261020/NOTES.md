# WhiteClock V1.0.0

适用于 CW32L010F8U6 / 152 × 296 黑白墨水屏时钟。设备界面版本显示 `WhiteClock V1.0`。

## 功能

- 七套主题：错版、撕纸、头版、半调、几何、日牌、织纹。
- SET / BACK 两键操作，左侧圆点菜单，末尾只读版本行。
- 时间、日期、星期、12 / 24 小时制和定时反色。
- 主页 BACK 进入番茄钟，5 / 15 / 25 / 45 / 60 分钟，到时五次全刷提醒。
- 主题资源按扫描顺序读取，独立背景 / 字形缓存，无整屏帧缓冲。
- 原厂 LUT、完整 OLD / NEW 上传、周期全刷；裁剪窗口关闭，两种波形边框均 `0x47`。

## 烧录

使用同版本 BIN 和 manifest，先确认接线并备份本台设备全部 64 KiB，再按页写入应用、完整回读校验。设置页 `0xFA00` / `0xFC00` 与安全页 `0xFE00` 不擦写。不得将参考设备原厂备份用于其他设备恢复。

## 限制

芯片温度不是校准室温；番茄钟状态不跨复位保存，无声音提醒。多批次兼容性、极端温度、长期残影、功耗和硬件栈水位未完整测量。空间抖动不等同于原生灰阶。
