# WhiteClock v1.1.0

## 低功耗优化

- 空闲时进入深度休眠，由 RTC 和按键唤醒，替代持续的毫秒级待机唤醒。
- 深睡期间暂停 SysTick，关闭闲置 SPI / ADC 时钟；操作和刷新时保持高速运行。
- 用 RTC 亚秒计数补偿睡眠时间，保留番茄钟、长按返回和按键连发。
- 适配深睡按键唤醒路径，增加同时按住 SET / BACK 上电的调试模式。
- 菜单版本显示更新为 `WhiteClock V1.1`。

## 验证

低功耗实现完成参考设备整片回读及唤醒、按键和刷新检查。正式镜像与实测程序仅版本文字一个字节不同；保留主机回归、固定画面散列和资源像素验证。详细边界见[低功耗说明](../../docs/LOW-POWER.md)。

## 烧录

先备份本台设备完整 64 KiB，再以即时整片哈希保护应用写入并完整回读。设置页 `0xFA00` / `0xFC00` 与安全页 `0xFE00` 不擦写。需要调试时可同时按住 SET / BACK 上电约 1 秒，本次运行禁用深睡；正常重启恢复。
