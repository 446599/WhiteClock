# v4.1 · 抖动翻页时钟

在 `codex/desktop-clock-v4` 上替换原“翻页”主题（仍是主题索引 1），不迁移或清空设置，不修改 `master`。这是固件内实际绘制的界面，不是概念图。

## 外观和使用

主页按 K2 切换到“翻页”，或在设置 → 显示主题中选择翻页后保存。已有显示设置继续保留；升级不会强制更换你保存的主题。

两组 126×78 像素翻页卡片分别显示小时和分钟。卡片采用阶梯圆角、上下分层、1 像素折缝、左右铰链、顶边高光和右下投影。使用重新绘制的几何数字，原生 16×28 点阵按 2× 整数放大，数字笔画保持纯白、不使用抖动或抗锯齿。其他两套主题的字体不改变。

顶部保留完整日期和星期，底部显示时间制式/专注状态、芯温、一天进度。仅翻页主页隐藏常驻按键说明以留出空间，K1/K2 操作不变；主题选择页仍有操作提示。支持 12/24 小时制、午夜/中午、负温度、无效温度占位和专注暂停状态。

## 模拟灰度，不是原生灰阶或翻页动画

使用固定坐标的 4×4 Bayer 空间抖动，四档黑点覆盖率为 100%、87.5%、12.5%、0%。深灰用于上半卡片，浅灰用于投影和高光，最终屏幕数据依然只有黑、白两种像素。

抖动矩阵锚定在逻辑屏幕坐标，不随分钟、帧序号或卡片移动相位。旧帧和新帧可以独立重建同一纹理，避免刷新时整片背景更换点阵。文字没有灰边；本版不做时间抖动，不用多次局刷模拟灰度，也不增加翻页过渡帧。

夜间先还原逻辑灰度，再对最终 1-bit 像素取反，保证整帧逐位互补。屏幕传输端原有的黑白极性修正仍只执行一次，不与夜间模式混用。

这次不修改硬件驱动、原机 56 字节 LUT、刷新次数策略、SPI 分步发送或按键逻辑。渲染仍按列/19 字节行输出，未引入整帧 RAM 缓冲；绘图列表仍为 112 个操作。真实墨水屏上点阵的灰度观感、残影和刷新耗时需实机确认。

## 构建与预览

运行 `make -j2`、`make test`、`python3 tools/verify_image.py`，以及 `python3 -m unittest discover -s tests -p test_device.py`。首次构建需要下载已固定哈希的 Unifont 字体依赖；本主题新数字不依赖系统字体。

`python3 tools/preview_flip.py` 从固件同一函数 `clock_render_row` 的实际行数据解码图像。输出 `design/flip-clock-v4.1.png` 为六状态预览，`design/flip-day.png` 和 `flip-night.png` 是 296×152 原尺寸 1-bit 图，`flip-day-4x.png` 是最近邻 4 倍图。这些文件由 Actions 构建生成，随对应提交的固件产物提供，不是设备照片。不要将单独的连续灰阶参考 `.pgm` 当成实际屏幕效果。

新增回归检查覆盖矩阵黑点覆盖率/周期、整帧夜间互补、像素数字、所有分钟数字位置、设置/专注/错误覆盖层、绘图边界和 112 操作预算；EPD 测试增加了抖动旧/新帧及传输极性检查。其他 RTC、设置掉电、温度、按键/SPI、烧录保护测试仍保留。

## 验收状态

此版本为候选固件，未在这次开发中烧录或实机测量。以对应提交的 Actions 结果及 `manifest.json` 为构建、测试、哈希和内存占用依据，历史 `build/` 镜像不代表当前输出。

刷入后重点确认：翻页主题白底黑卡、近距离颗粒与正常观看距离下的灰度观感、夜间模式、跨分钟残影，以及屏幕 BUSY 期间连续按键的响应。芯温仍是 MCU 内部温度的近似值，不是校准室温。
