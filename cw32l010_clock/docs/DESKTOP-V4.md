# 桌面钟表 v4 候选固件

开发分支：`codex/desktop-clock-v4`。基于 v3 的 `091ce0f`。本版本未烧录、未实机验收；主分支及 v1/v2/v3 历史恢复证据不改写。

## 外观

三套主题统一为纯黑白像素设计：留白大时钟、四卡片时钟、日历日牌。保留中文年月日、星期、12/24 小时制与可配置跨午夜反色。
主页增加一天进度线、芯温、统一两键提示；专注运行时左下显示剩余分钟。
中文使用 GNU Unifont 16.0.04 的原生 16 像素点阵，ASCII 为 8x16。大/中数字为原创 5x7 点阵的整数倍放大。
不使用 STHeiti/Arial、不进行抗锯齿或非整数缩放，文字不做模拟灰度。`design/desktop-v4.png` 是同一份 C 渲染器生成的预览，不是设备照片。

## 两键操作

K1=PB2，K2=PB3，低有效；实际左右位置沿用 v3。每 5 ms 采样、20 ms 消抖。
K1 短按在松手消抖后触发，以免长按误执行短按；长按约 700 ms 返回/取消。K2 在按下消抖后响应；数字编辑沿用 500 ms 起始、150 ms 间隔连加。
主页 K1 进菜单，K2 切主题。菜单 K1 下一项，K2 确认。日期、时间与显示设置沿用原操作。

新增菜单“专注计时”：空闲时 K1 循环 5/15/25/45/60 分钟，K2 开始；运行时 K2 暂停，暂停时 K2 继续；运行/暂停时 K1 重置，完成后 K2 确认。长按 K1 返回菜单，计时继续。
使用毫秒单调时钟累计，暂停时间不计入；显示剩余分钟向上取整，不伪造秒级刷新。到时显示完成页，不自动循环、不承诺响铃。编辑其他设置时不强制跳页，避免丢失草稿。
专注状态在重启后重置；不将每秒/每分钟进度写入 Flash。

## 响应与屏幕

SPI 改为 begin/poll：单轮最多发送 8 字节，TXE/BUSY 不就绪立即返回；单事务总超时 5 ms。屏幕 BUSY、复位延时、RTC 保存窗口和 ADC 采样均使用状态机。
主循环先消费按键，传输阶段不强制睡眠 1 ms，空闲/BUSY 等待时 WFI。刷新合并静默时间从 80 ms 降到 20 ms。
在 NEW 帧发送前允许替换为最新 UI；开始发送后保持整帧快照不变，避免撕裂。波形进行中按键仍被处理，下一帧使用最新状态；不会将每次连按排成一长串旧画面。
仅在发送端对旧、新两帧的每个数据字节取反；逻辑白底与定时反色不混用。保留 v3 旋转方向、原机 56 字节 LUT、首次全刷/最多七次快刷/反色强制全刷和故障后的全刷重试。不写未知波形。
墨水屏物理刷新时间未改变，没有“零延迟”或实测毫秒数承诺。新增 `main_loop_max_ms`、`epd_poll_max_ms`、`temperature_failures` 供 SWD 验收。

## 芯温

内部 ADC 通道 14 采温度、15 采 1.2 V 参考，分频 8、最长采样保持 390 时钟。
每 60 秒供电采样，等待稳定 2 ms，丢弃首组后平均 16 组，并作 1/4 权重低通滤波。每组转换超时 20 ms；不等待 ADC 的 while 循环。完成或失败关闭 ADC/温度/带隙使能。
读取 SDK 定义的工厂 T0(0x001007CD) 和 TRIM(0x001007CE)，按 SDK `ADC_GetTs` 公式定点换算；供电电压通过内部 1.2 V 通道估算，不写死 3.3 V。
显示整数摄氏度“芯温”，无有效标定、ADC 超时或不合理结果时显示 `--°C`，不保留过期读数。
这是芯片结温的近似值，受内部参考公差、负载、自热和外壳影响，不是校准室温计，也不宣称房间温度精度。
公式来源：仓库 `lib/inc/cw32l010_adc.h`、`lib/src/cw32l010_adc.c`（WHXY SDK，2024-08-07）。

## 构建与验收

`make -j2` 自动准备字体后交叉编译；首次构建需要网络下载固定版本，后续可使用 `build/font-cache` 离线缓存。
`make test` 运行 ASan/UBSan 主机测试；`python3 tools/verify_image.py` 验证原始备份哈希、向量、镜像边界、未解析符号和至少 1 KiB 栈空间；安装 pyocd 后运行 `python3 -m unittest discover -s tests -p test_device.py`。
不要使用仓库里旧的 `build/` 文件冒充本次输出；以当前 Actions 产物和 `manifest.json` 为准。字体构建依赖不作为下载附件提供；产物附带字体许可说明。
烧录沿用 `tools/device.py` 的只读检查、实时备份、预期整片哈希、局部擦写与全片回读保护。当前 v3 设置会改变整片 Flash 哈希，不沿用旧 v1 示例哈希，不自动解锁、不整片擦除。
实机重点：白底黑字/夜间反色、负温度与无效温度占位、快速连续按键/屏幕 BUSY、长按不误触短按、专注暂停/完成、掉电显示设置恢复、温度稳定性、残影与功耗。
