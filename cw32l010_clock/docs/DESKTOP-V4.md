# WhiteClock 架构与硬件

## 硬件接口

| 功能 | 连接 |
|---|---|
| MCU | CW32L010F8U6，24 MHz HSI，64 KiB Flash / 4 KiB RAM |
| 面板 | 物理 152 × 296，横向 UI 296 × 152 |
| 屏幕 BUSY / RST / CS / DC | PA1 / PA2 / PA3 / PA4 |
| SPI SCK / MOSI | PA5 / PA6，6 MHz |
| BACK / SET | PB2 / PB3，低有效 |
| SWDIO / SWCLK | PA7 / PA8 |
| RTC | 32768 Hz LSE |

板卡焊盘顺序、电源接口和 SWD 电平需针对具体硬件确认，见[烧录教程](FLASHING.md)。

## 输入与界面

GPIOB 双边沿中断只登记按键采样掩码，1 ms SysTick 对活动按键消抖。SET 按下确认，保持 500 ms 后每 150 ms 连发；BACK 按下投递下一项，消抖后保持 700 ms 投递一次返回，松手不补发事件。

主页 SET 进入设置，BACK 进入番茄钟。菜单包含时间、日期、制式、反色、主题与专注计时，末尾为只读版本行。编辑草稿与已保存设置分离，取消不提交；RTC 保存失败保留重试状态。

## 协作调度

主循环优先取按键，5 ms 合并显示更新。EPD、ADC 和 RTC 保存以状态机推进，不在中断里访问 UI 或 Flash。NEW 帧发送前允许更新待显示状态，开始发送后冻结快照，避免混帧。

SPI 每轮最多 64 次状态读取、8 字节发送。连续无进展上限 5 ms，总事务上限为 10 ms 加每字节 1 ms；没有强制的逐字节 1 ms 休眠。

## 显示资源

七套主题使用固定压缩位图与字体子集，按面板扫描方向读取。背景、字体分别用 512 字节解码缓存；背景按整字节覆盖，字形按列取位。物理行缓冲为 19 字节，不分配 5,624 字节整屏缓冲。

日常使用原机差分快刷 LUT，但完整上传 OLD / NEW 双帧。首屏、反色和七次快刷后的下一次更新使用完整波形。裁剪窗口默认关闭，全刷与快刷边框均为 `0x47`；具体协议与限制见[驱动分析](EPD-DRIVER-RESEARCH.md)。

## RTC、设置与温度

RTC 保留有效 LSE 和日期时间，按字段单独保存。设置采用 `0xFA00` / `0xFC00` 双页、序号、CRC 和最后提交标记，变化后延迟写入；安全页 `0xFE00` 不写入。

内部温度采样包含稳定等待、丢弃首组、16 组平均和低通滤波，单组转换有超时。内部温度不是校准室温计，无有效读数时显示占位符。

## 番茄钟

时长为 5 / 15 / 25 / 45 / 60 分钟，可开始、暂停、继续和重置。后台计时不依赖所在页面；完成后请求五次实际完整波形刷新，任意按键取消尚未执行的提醒，当前波形正常结束。计时状态不跨复位保存。

## 调试指标

`clock_ui_state` 记录界面、待显示和已显示页面；按键计数与 EPD 阶段耗时用于区分输入、传输与物理波形等待。读取地址必须来自匹配构建的 manifest，不使用其他镜像的地址。
