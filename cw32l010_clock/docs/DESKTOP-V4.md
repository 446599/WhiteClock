本文保留各轮实现和验收的历史记录，后续进展按时间追加。当前 WhiteClock V1.0 状态以[仓库首页](../../README.md)和[发布记录](../releases/whiteclock-v1-fast-20261020/NOTES.md)为准。

早期开发分支：`codex/desktop-clock-v4`，基于 v3 的 `091ce0f`。2026-10-04 的按键中断与翻页界面镜像完成全片回读和首次刷新验证，当时外观与实际操作仍待用户验收；此历史阶段不代表当前版本状态。

## 外观

当前七套主题为错版、撕纸、头版、半调、几何、日牌、织纹，对应原设计编号 01、03、11、15、16、18、20；旧六主题不再包含于固件。保留实时日期、星期、12/24 小时制、温度与可配置跨午夜反色，各主题使用不同字形、黑白抖动和纹理。
主页保留 SET/BACK 两键提示。菜单中文使用 GNU Unifont 16.0.04 原生点阵；主题字形使用 DejaVu 精简子集及原设计数字元素，构建时生成 1-bit 图像，设备不执行字体栅格化。
七张背景和十八张字形图集按面板扫描方向存储，采用原始位图、分块字典或分块差分压缩；背景和字形分别使用 512 字节解码缓存，不分配全屏帧缓冲。预览由同一份 C 渲染器生成，不是设备照片。

## 两键操作

快捷入口和提醒始于 `uc8251-seven-dot-focus-20261020`。当前安装版为 `whiteclock-v1-fast-20261020`，已完成整片回读；用户确认反应明显变快，按住 BACK 即可返回。

按用户确认的机身标识，BACK=PB2（原 K1），SET=PB3（原 K2），低有效。之前固件的 SET/BACK 语义与机身相反，现已在统一引脚定义和采样路径一起纠正；屏幕不再显示 K1/K2。PB2/PB3 使用 GPIOB 双边沿中断捕获，1 ms SysTick 只对发生边沿或仍按住的键做 20 ms 消抖、长按和连发处理。
SET 按下消抖后触发确认/修改，按住满 500 ms 后每 150 ms 连发；BACK 短按在按下消抖后立即切到下一项，按住约 700 ms 就返回/取消，不等待松手，继续按住和松手均不重复返回。主页 SET 进菜单，主页短按 BACK 进入番茄钟，长按 BACK 返回主页。
菜单和编辑页面使用 SET 确认/修改、BACK 下一项；主题和时间制式页面同样由 SET 保存、BACK 切换。主题切换即时预览，SET 保存，长按 BACK 取消；七个主题序号为 0..6，设置页格式不变。已有 0..5 序号保留，但对应新的设计。
列表选中项使用文字前方的 8x8 实心圆点，不再将文字与整行底色反色。菜单末尾为只读 `WhiteClock V1.0`，不能选中或点击，六个功能入口与长按 BACK 返回保留。时间/日期数字编辑下划线和定时夜间反色功能不变；夜间圆点随整页极性显示。

菜单“专注计时”即番茄钟：空闲时 BACK 循环 5/15/25/45/60 分钟，SET 开始；运行时 SET 暂停，暂停时 SET 继续；运行/暂停时 BACK 重置，完成后 SET 确认。长按 BACK 返回入口页面（主页或菜单），计时继续；重新进入不重置正在运行的倒计时。
使用毫秒单调时钟累计，暂停时间不计入；显示剩余分钟向上取整，不伪造秒级刷新。到时通过原厂完整波形全刷 5 次，不自动循环、不承诺响铃。每次成功完成实际刷新才减少提醒次数，失败沿用 60 秒重试保护；未发生实际刷新的完成事件不计数。任何按键停止后续提醒，已开始的刷新自然完成。编辑其他设置时不强制跳页，提醒在当前页面执行，避免丢失草稿。
专注状态在重启后重置；不将每秒/每分钟进度写入 Flash。

## 响应与屏幕

SPI 改为 begin/poll：单轮最多发送 8 字节，TXE/BUSY 不就绪立即返回；连续无发送进展超时 5 ms，事务总时限为 10 ms + 每字节 1 ms；56 字节 LUT 在实机上不能用固定 5 ms 总时限。屏幕 BUSY、复位延时、RTC 保存窗口和 ADC 采样均使用状态机。GPIO 按键 ISR 只投递边沿掩码，不在中断里访问 UI、Flash 或 EPD。
主循环先消费按键，传输阶段不强制睡眠 1 ms，空闲/BUSY 等待时 WFI。当前刷新合并静默时间为 5 ms。
在 NEW 帧发送前允许替换为最新 UI；开始发送后保持整帧快照不变，避免撕裂。波形进行中按键仍被处理，下一帧使用最新状态；不会将每次连按排成一长串旧画面。
仅在发送端对旧、新两帧的每个数据字节取反；逻辑白底与定时反色不混用。保留 v3 旋转方向、原机 56 字节 LUT、首次全刷/最多七次快刷/反色强制全刷和故障后的全刷重试。不写未知波形。
墨水屏物理刷新时间未改变，没有“零延迟”或实测毫秒数承诺。新增 `main_loop_max_ms`、`epd_poll_max_ms`、`temperature_failures` 供 SWD 验收。

## 温度

内部 ADC 通道 14 采温度、15 采 1.2 V 参考，分频 8、最长采样保持 390 时钟。
每 60 秒供电采样，等待稳定 2 ms，丢弃首组后平均 16 组，并作 1/4 权重低通滤波。每组转换超时 20 ms；不等待 ADC 的 while 循环。完成或失败关闭 ADC/温度/带隙使能。
读取 SDK 定义的工厂 T0(0x001007CD) 和 TRIM(0x001007CE)，按 SDK `ADC_GetTs` 公式定点换算；供电电压通过内部 1.2 V 通道估算，不写死 3.3 V。
显示整数摄氏度“温度”，无有效标定、ADC 超时或不合理结果时显示 `--°C`，不保留过期读数。
这是芯片结温的近似值，受内部参考公差、负载、自热和外壳影响，不是校准室温计，也不宣称房间温度精度。
公式来源：仓库 `lib/inc/cw32l010_adc.h`、`lib/src/cw32l010_adc.c`（WHXY SDK，2024-08-07）。
