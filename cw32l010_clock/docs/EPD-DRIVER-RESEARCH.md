# 墨水屏驱动分析

## 兼容范围

目标面板物理分辨率 152 × 296，BUSY 低有效，使用旧图像 `0x10`、新图像 `0x13` 和刷新 `0x12`。当前实现采用 UC8251 单字节 PSR 协议路径，具体面板 FPC / 控制器料号仍未完全确认。尺寸和命令相似不能作为替换波形或提高电压的依据。

原始协议来自参考固件反汇编，见[原厂分析](../../cw32l010_epd_analysis.md)。参考镜像 SHA-256：

```text
0f92f36672594320223d3a23815bd04f864b1163875ef61d41a2460bd0c80c71
```

## 出厂刷新流程

| 参考固件地址 | 行为 |
|---|---|
| `0x2CB8`、`0x2D44..0x2ED8` | 比较前后场景、合并变化区域、七次差分后全刷 |
| `0x30E6` | 按行生成和传输，不保存完整帧缓冲 |
| `0x3234` | 初始化分辨率、PLL、电压和五张 56 字节 LUT |
| `0x33A0` | 包含末端的窗口，横坐标按 8 像素对齐 |
| `0x381A` | `0x12` 刷新并等待 BUSY |
| `0x3800` | `0x02` 关电源，随后 `0x07 : A5` 深睡眠 |
| `0x3838` | BUSY 低有效，起始等待、超时与释放延迟 |

出厂窗口路径为 `0x90 → 0x91 → 0x10 → 0x13 → 0x12 → 0x92`，不能直接套用其他驱动的窗口顺序。该路径的裁剪传输在参考硬件出现显示异常，因此 WhiteClock 正式配置关闭裁剪窗口；测试保留窗口计算覆盖，不表示默认启用。

## 正式配置

- 完整 OLD / NEW 各 5,624 字节，合计 11,248 字节。
- 原机完整 / 差分 LUT，每个命令表长 56 字节。
- 单字节 PSR、原始数据极性，全刷 / 快刷边框参数均 `0x47`。
- 首屏、反色变化和七次差分快刷后的下一次更新使用完整波形。
- 每轮保留初始化、必要 BUSY 等待、关电源和深睡眠。

不要把“差分快刷波形”与“仅发送局部窗口”视为同一选项；当前前者开启、后者关闭。

## 性能实现

主题资源按面板扫描顺序编码，背景按字节覆盖、字形按列读取，独立 512 字节缓存减少反复解压。物理行仅使用 19 字节缓存，适应 4 KiB RAM。

核心为 24 MHz、SPI 为 6 MHz；有界短突发在主循环间隙推进，不在等待 SPI / BUSY 时长时间阻塞输入。新帧开始发送后冻结场景，完成当前波形后处理后续变化。

本地芯片定义和手册没有可确认的 SPI DMA 通道。SDK 的 `SPI_DMACmd()` 会操作 `SPI_CR1.MODE[17:16]`，与 SPI 模式位重叠，不能当作真实 DMA 使能接口；当前不使用该函数。

刷新指标分为准备、OLD、NEW、BUSY 和收尾。数据量下降、主机解压减少或启动首刷耗时，均不能直接换算成按键到画面的提速比例。

## 相似屏驱动对照

以下为协议研究来源，不是可直接移植的配置：

| 驱动 | 相关性与限制 |
|---|---|
| [GxEPD2_260](https://github.com/ZinggJM/GxEPD2/blob/master/src/epd/GxEPD2_260.cpp) | 同为 152 × 296，使用 OLD / NEW；LUT 长度 44 / 42 字节，与参考表不一致 |
| [GxEPD2_260_M01](https://github.com/ZinggJM/GxEPD2/blob/master/src/epd/GxEPD2_260_M01.cpp) | 相似分辨率与双图像命令，面板与波形配置不同 |
| [Waveshare EPD_2in9d](https://github.com/waveshareteam/e-Paper/blob/master/RaspberryPi_JetsonNano/c/lib/e-Paper/EPD_2in9d.c) | 可对照 BUSY / 局部指令，分辨率为 128 × 296，不可照搬 |
| [GxEPD2_266_BN](https://github.com/ZinggJM/GxEPD2/blob/master/src/epd/GxEPD2_266_BN.cpp) | 尺寸相近但属 SSD1680 指令体系，不能混用其写图像 / 更新命令 |

原生四灰、跨温度波形和其他批次面板尚无完整兼容结论。当前抖动主题使用黑白空间网点，不写入未知灰阶 LUT。
