# CW32L010 黑白墨水屏时钟

v3 已于 2026-10-04 烧录，完整 64 KiB 回读一致，首屏刷新成功，RTC/EPD/按键溢出计数无错误。屏幕方向与按键手感仍待用户确认。
针对用户反馈旋转画面 180°，加入中文日期/星期、菜单、12/24 小时制、定时反色和三套主题。

## 按键操作

K1 = PB2，K2 = PB3，低电平按下；两个按键的实际左右位置待实机确认。

| 场景 | K1 短按 | K1 长按约 0.7 秒 | K2 |
|---|---|---|---|
| 时钟主页 | 进入设置 | 进入设置 | 切换主题 |
| 设置菜单 | 下一项 | 返回主页 | 进入选项 |
| 时间/日期/反色编辑 | 下个字段，最后为保存项 | 取消未保存修改 | 加一/开关；选中保存项时保存 |
| 时间制式/主题选择 | 切换选项 | 取消返回 | 保存 |

K2 编辑数字时按住 0.5 秒开始连加，间隔 0.15 秒。按键消抖 20ms。
修改时间保存后秒归零；修改日期不改变当前时间，星期自动计算，年月变更自动约束月末日期。
日期范围 2000—2099，12 小时显示带上午/下午，午夜和中午显示 12。

中文菜单：时间设置、日期设置、时间制式、定时反色、显示主题、保存返回。
反色默认关闭，预设时间为 22:00—07:00；可改开始/结束时分，支持跨午夜；开始等于结束表示全天反色。
设置确认后静置约 2 秒保存到 Flash，刷新进行中则延后保存。
使用 0xFA00/0xFC00 两页交替保存，CRC 校验，提交标记最后写入；配置不变不写入。
0xFE00—0xFFFF 最后安全配置页不用于设置，不做擦写。
时间保留依赖 RTC 供电，完全断电后需重新校时；显示配置可掉电保留。

## 显示与灰度

三套主题：留白、翻页、日历。`design/themes-comparison.png` 左列为四灰设计，右列为本版实际使用的黑白点阵灰度。
`design/menus-comparison.png` 为六个中文设置页面设计预览。
所有预览由固件同一套 C 渲染代码生成，不是实拍；精确屏幕控制器和原生灰度能力尚未确认。

原机驱动每张 LUT 为 56 字节，使用备份提取的原始全刷/快刷表。
找到的 UC8151 灰度实现使用 42/44 字节 LUT，不能据此确认与本机兼容，未移植、未对屏幕试写未知波形。
原生四灰仍需屏幕排线型号/控制器文档或匹配原机的灰度波形证据。
参考：https://github.com/antirez/uc8151_micropython/blob/main/uc8151.py

刷新驱动分步执行，BUSY 等待不阻塞主循环；每轮发送最多四行数据。
首次全刷，后续最多七次快速全帧更新后全刷；反色切换强制全刷。
刷新时继续消费按键，下一帧合并最新状态。失败不提交显示状态，60 秒后重试。
墨水屏的物理刷新耗时依然存在，实机响应/残影待验证。

## 硬件

CW32L010F8U6，20 引脚，64 KiB Flash、4 KiB RAM。

| 功能 | 引脚 |
|---|---|
| BUSY（低为忙） | PA1 |
| RST / CS / DC | PA2 / PA3 / PA4 |
| SPI SCK / MOSI | PA5 / PA6，AF3 |
| K1 / K2，内部上拉 | PB2 / PB3 |
| SWDIO / SWCLK | PA7 / PA8 |

RTC 使用实测原机外部 LSE 32768 Hz，PSC=16383；保留有效运行中的 LSE 时间/校准。
未做电池续航优化，仍使用 1ms SysTick 与 WFI；不能据此承诺续航。

## 构建验证

```sh
make -j4
make test
python3 tools/verify_image.py
/opt/anaconda3/bin/python -m unittest discover -s tests -p 'test_device.py'
```

ARM GCC 16.1.0 裸机构建，无 newlib、无动态分配；实际占用及哈希见 `build/clock/manifest.json`。
静态 RAM 1168 字节，另保留最少 1024 字节栈；按列/行渲染，无整帧缓存。
主机测试带 ASan/UBSan，覆盖全世纪日历/星期、时间编码、反色边界、按键/编辑、旋转渲染、
原机全刷/快刷指令、BUSY/SPI 失败、RTC 访问、设置每个写入边界断电恢复和烧录保护。
主机模拟不替代实机面板、Flash 时序和走时精度验证。

字体为本机 STHeiti/Arial 栅格化子集，仅用于本次设备样机；对外分发前需核实字体许可或更换开放字体。

## 集中连接烧录

设备自行供电，WCH-Link 只接 SWCLK、SWDIO、GND。准备完成后再夹住触点，保持到回读完成。

```sh
/opt/anaconda3/bin/python tools/device.py --flash --frequency 50000 --expected-before-sha256 153c111b44d466e5bec946a0ea0cae5ba18d4e49a1915d82680dfd18ace4ff22
```

上面哈希仅适用于当前已验证的 v1。任何不一致先检查另存的实时备份，不绕过检查。
后续 v3 设置写入会改变全量 Flash 哈希，不能把旧哈希当成后续设备状态。
烧录前校验芯片/容量/读保护/镜像/备份，禁止自动解锁；只擦写程序覆盖的页并保留末页剩余字节；
全 64 KiB 逐字节回读验证，软件复位并检查调试计数。
记录保存到 `../evidence/`。`--restore` 使用已校验的原始 64 KiB 镜像恢复。
